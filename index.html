HOW TO PLAY

You'll hear spatial premises like "B is North of C." Your job: was the n-back-ago premise the same kind as this one? Press MATCH or NO_MATCH.

At N=1, compare to the previous trial. At N=2, two trials back, and so on.

Match Rules per Mode

Mode 0: Same single direction (e.g., both "X is North of Y").

Mode 1: Same diagonal pair (e.g., both "North and East").

Mode 2: Same two directions in same order across three objects.

Mode 3: Same inner and outer direction (one applied to both objects).

Mode 4: Same corner directions + same connecting direction.

Mode 5: Same transformation type (Inversion vs Rotation) and same axis (V/H/mixed) on both pairs.

Tips

Symbol letters (B, C, X, etc.) are distractors — only the directional structure matters.

Use Adaptive N to let the game auto-tune difficulty (the Jaeggi protocol).

Cognitive Interference controls how often consecutive trials share letters in interfering ways (e.g., "S is N of J" then "J is N of P"). Higher = harder, less drift. 75% is the recommended default.

d' (d-prime) measures discrimination ability from signal detection theory. Higher is better. 1.0 = decent, 2.0 = excellent.
